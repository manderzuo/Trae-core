## 真实发现与修复

1. 辅助模型把“延长上传视频”判断为 `continue`，Core 却将其解释成必须有历史父版本的尾帧续写。修复为：仅在没有父版本、用户未明确指定历史续写、且存在已校验视频素材时，将其作为整段视频素材的新生成；保留完整提示词和视频。显式历史续写、图片输入不降级。
2. 缺少父版本等明确失败未结束父操作，客户端持续显示 queued。通过现有存储 CAS 结束已明确失败的操作，不释放未知执行或伪造付费退款。
3. 真实 GLM 补充 `watermark:false`，但未显式传水印字段时 Core 误拒绝。仅允许辅助模型复述实际默认/继承值，不允许更改未指定的水印设置，其他规格约束保留。
