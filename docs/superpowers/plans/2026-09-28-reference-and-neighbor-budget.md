# 参考素材续接与相邻规格预算修复

用户指令：未知视频费用可参考相邻规格预占，取得真实费用后立即结算并记住规格；修复参考图丢失；推送已解决修改。本轮不部署、不新建付费视频、不清除未知账目、不创建子代理。

## 实施顺序

- [x] AI Work：先复现缺少精确规格的政策拒绝，允许相同模型、分辨率及素材类别的相邻时长预算；优先较长规格，无较长规格时按时长比例向上外推。不是实际扣费。
- [x] AI Work：复用已有持久化准备单与最终回执，按执行账号/精确规格读取已确认费用，增加风险余量作为下次预占。冲突、失败、未知及零费用不形成标准。
- [x] Core：复现客户端图片预处理与视频提交分成两个请求的丢图；返回加密、Key 绑定、短期有效的素材续接标记，后续仅消费显式带回的标记/图片/素材 ID，不按 Key 全局复用最近图片。
- [x] Core：支持同一对话中已有用户参考图；明确要求参考图却没有素材时拒绝视频提交。继续验证素材归属、过期、格式、数量和上传权限。
- [x] 验证：覆盖跨 Key、过期与篡改、规格隔离、真实回执重启后复用；重跑 Core 回归和 AI Work 回归，不停止生产进程。
- [x] 自审、记录实际结果，将两个工作区既有规格修复与本轮改动整理为独立提交；推送目标为各自原修复分支，推送结果另以远端 SHA 核验。MCP 没有本轮改动不制造提交。

## 规则与边界

预占优先真实精确规格记录，然后精确有效政策、相邻记录/政策；账本最终始终使用真实回执。单次历史费用是校准样本，不是上游固定价格保证。邻居不得跨清晰度、模型、图片数、参考视频数量/时长。显式过期政策不是无限额度许可，必须有有效邻居或有效历史样本。未知费用仍只保留本笔预占，不冻结整把 Key。

参考素材标记只携带已验证的素材 ID，使用现有 KeyVault 独立上下文认证加密；客户端返回标记不等于绕过素材权限。未传图片/ID/标记的客户端不能由服务器读取本地文件；明确失败不允许悄悄改成纯文字视频。

## 进度

原有全角规格及画幅报价修改保留；两工作区均为现有独立 worktree。本轮采用本人实施及自审，按用户偏好不创建子代理。测试临时目录放 D 盘，复用既有编译缓存。

## 参考素材协议与自审结果

客户端把图片预处理成文字描述时，Core 将原图保存为自有素材并把 `[AIWORK_REFERENCE:...]` 加密标记附在响应中。后续请求必须保留该标记，或者携带原始 inline 图片 / 有效的自有素材 ID。同一提交对话中明确要求参考图片时，也可续接前一条用户消息的图片。

标记绑定当前 Key，最长有效期三十分钟且不能超过素材有效期。跨 Key、篡改、过期、已失效图片及无效显式素材列表都在付费辅助请求之前拒绝。标记只用于传输，解码后从提示词剥离，不发送给辅助模型。图片验证及文件读取放在线程池，不阻塞异步请求线程。

已使用隔离测试先复现两项额外边界缺陷（合法标记掩盖无效素材列表、合法标记引用已失效图片），然后修复。服务器不会因为“图片之前见过”就按 Key 全局取最近图片，避免同 Key 多客户端并发串图。

现有可信回执事件及账目对账通道为两秒调度周期；本轮沿用其请求/Key/预算身份核验和幂等结算机制。不承诺上游尚未发布账单时能够立即结算。

客户端如果丢弃所有图片和标记，服务器仍无法读取客户端本地文件。明确要求参考图时返回错误，不退化成付费纯文字视频。标记续接不意味着辅助文字模型具备视觉识别能力，也不宣称新版本已做客户端实机付费验收。

不属于本轮修复范围：DSH 下载工具失败的细分诊断、聊天输入 413、观察者竞争 429、MCP 通用 503 错误呈现和旧未知账目的处置。所有未核验账目保留。
