# Seedance 工作区交付

视频完成后，Core 应通过客户端实际声明的工具下载 MP4 到该客户端工作区，而不是仅返回一句下载提示。首先支持已核验的 Trae Work `RunCommand`（PowerShell 5）契约；不虚构其他客户端的工具。没有适配工具、工具被禁用或客户端执行失败时，明确给出下载方式，不谎称本地保存成功。

工具调用必须使用 OpenAI `tool_calls` 与 `finish_reason=tool_calls`，流式调用必须含 `index`，结束 `[DONE]`。工具结果回传只确认原任务交付，不重新调用 DeepSeek/Seedance，不重复生成或占用计费并发。

命令只能访问此 Key 自己已完成的视频，通过 15 分钟、单任务、仅下载的加密授权；不传出永久 Key。下载时重新核验 Key、用户、作用域及任务归属。授权不得写入公网访问日志。命令遵从客户端权限，不绕过客户端审批。

最终文件优先保存到请求系统上下文明确给出的 final workspace，缺失时使用客户端终端当前目录。文件名绑定请求编号，已存在时不覆盖；下载使用唯一临时文件、超时、大小/MP4 头验证与原子移动。成功须有客户端工具返回的路径与文件大小回执。

本轮仅改 Core；保留全部账本和未知扣费占用。验收优先复用已完成视频，不新增付费生成。临时测试文件放 E 盘并在验收后清理。
