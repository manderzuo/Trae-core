# Seedance 直接 API 自动下载

用户已要求开始修改与部署；由当前代理执行，不启用子代理。

- Seedance 的意图辅助及下载调度模型为 `glm-5.3-flash`，与普通文字请求默认模型分开。
- 视频完成后将客户端已声明、权限允许的下载终端工具交给辅助模型选择；返回标准 Chat Completions tool_calls，兼容 SSE。
- 不依赖 MCP、Skill 安装目录或接收程序。使用随 API 工具调用返回的受控下载命令；默认取本机系统 Downloads 路径，支持 Windows PowerShell / Git Bash、Unix Bash。
- 模型只能选择受支持工具及受控参数，不允许执行模型自由编写的任意命令。永久 Key 不进入模型/命令；下载凭证仅对应当前 Key 的已完成视频，15 分钟过期。
- 下载规划是有独立幂等标识的文字请求，走现有真实计费链路，不能伪造免费上游调用。模型不可用或额度不足时以已校验工具直接交付，不能把已生成视频变成 503。
- 下载工具结果按任务归属和结构化回执关联；容忍客户端重写 tool_call_id、省略 assistant 元数据、包装 stdout。不因此重新生成或调用付费模型。
- 临时 .part、内容类型、MP4 头、大小、传输完整性和不覆盖已有文件保持校验。工具未开放、明确禁用联网或执行被拒绝时如实降级。
- 不清账、不释放原未知扣费；本轮公网验收复用已有视频，不新增视频生成。

验收：失败先行的协议测试；实际系统命令执行；Core/Router 全套；Linux 构建；公网普通 Key 交付、SSE、回执重写、下载哈希及不重新生成；保留账本和回滚版本后部署。
