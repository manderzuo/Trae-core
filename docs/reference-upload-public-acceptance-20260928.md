# API 本地参考图上传修复及公网验收

## 结论

2026-09-28：已修复 TRAE Work CN 已观测的 `uploaded_files/file_path` 本地图片附件不能进入 API 视频生成的问题。公网 `api.gemstory.cn` 已部署代码 `0be1c5d`，真实带图生成、SSE 工具回合、自动下载、实际积分结算均通过。

不是放开缺图拦截：客户端先使用本次上传授权发送原图，Core 确认所有图片收到后才进行辅助模型/视频付费调用。用户长期 API Key 不会下发到工具命令。

## 实现与隔离

- 复用客户端已声明的 PowerShell/Bash 终端，不依赖 AI Work MCP 或预装上传脚本。
- 当前附件限定为 PNG/JPEG/GIF/WebP 绝对本地路径，每次最多 10 张、每张 32 MiB。
- 30 分钟、仅限上传的授权置于请求头，不放 URL。数据库加密保存原请求，逐槽位绑定实际收到的素材。
- 同 Key 多会话不共享“最近图片”。跨 Key、被撤销 Key、过期或篡改授权均拒绝。
- 相同槽位只能重传相同字节；不同内容拒绝；工具输出伪造的素材 ID 不参与恢复。
- 首次响应幂等重试复用上传会话；工具回传以固定幂等键恢复原始提示词和规格，避免重复付费。
- 未成功上传完整素材时，不提交视频、不占视频执行并发。到期加密上下文由现有周期清理流程删除。
