# 参考图上传工具回报兼容修复

## 证据与范围

2026-09-28，公网 TRAE Work CN 的参考图上传后报 `invalid_delivery_tool_result`。
只读检查发现上传会话 `608bbaf1de932f673ce3fa254a29181c` 的一个槽位已绑定服务器素材，PNG 为 204,125 字节；没有这个上传会话对应的生成请求。问题发生于上传成功后的工具回报续接，不是图片未到 Core。

原代码只通过 `call_ref_upload_` 工具编号识别续接，未读取上传脚本已输出的 `SEEDANCE_REFERENCE_UPLOAD` 回执。工具编号被改写或遗漏的回报会误入下载处理；带冲突会话编号的上传回执也被原代码忽略。客户端该次原始回报未留存，因此不能断言其具体改写形式；本次覆盖了可复现的协议缺口。

## 修改

- 兼容原工具编号，以及终端 stdout 中携带的上传会话回执；支持 JSON 字符串、data/output/result/content 等包装、文本块及单个 Anthropic 风格 tool_result。
- 工具编号、所有回执、附件数量必须一致。不同会话、多个工具回报、下载工具编号混入、畸形/过大/过深输出直接拒绝，不选择最近上传，也不忽略冲突。
- 仍核验当前 Key、权限、有效期及服务器已完整收到的素材，恢复加密保存的原提示词和规格。不信任客户端伪造的素材 ID。
- 固定到上传会话的幂等键保持不变，重复回报复用同一任务，不重复生成或扣费。
- 失败回报返回参考图上传错误，不误报为视频下载错误。扣费、观察者及下载保存逻辑未改动。
