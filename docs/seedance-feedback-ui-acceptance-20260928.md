# Seedance 状态展示优化验收（2026-09-28）

## 修改范围

- Core 流式响应中的阶段文字缩短，每条以完整 Markdown 段落结束。
- 首条状态读取时同时标记已消费，后续相同阶段不重复追加。
- 20 秒连接心跳改用 SSE 注释，不写入聊天正文。
- 自上次阶段提示起等待满 60 秒，才显示简短等待提醒；后续每 60 秒一次。
- 新阶段立即反馈，并重新计算提醒间隔；临时查询异常仍说明会继续查询同一任务。
- `task_progress` 保留阶段、最近确认时间和本次连接等待秒数，新增 `kind=stage|waiting`。
- 不改计费、任务调度、参考素材上传、下载命令或客户端保存回执。

普通 Chat Completions 客户端仍使用追加式正文，不保证支持替换成动态卡片。
历史回复不会被本次更新重新排版，优化适用于后续响应。
